# Interaction Patterns

Status: VERIFIED unless marked.

---

## 1. Draft model (the central interaction rule)

Every edit writes to `item.draft`; nothing is written to disk until the user saves (or autosave fires).

```js
if (!item.draft) item.draft = cloneDeep(item);
item.draft.request.url = action.payload.url;
```

Consequences visible in the UI:

| Indicator            | Meaning                                                   |
| -------------------- | --------------------------------------------------------- |
| Dot on tab           | Draft differs from saved                                  |
| Save button enabled  | `hasRequestChanges(item)` true                            |
| Save shortcut        | ⌘/Ctrl + S                                                |
| Autosave             | Optional debounce (`enable auto save`, `auto save delay`) |
| Close-with-changes   | Confirmation dialog (`ConfirmAppClose/SaveRequestsModal`) |
| External file change | Watcher updates `item`, draft retained                    |

Source: `slices/collections/index.js` (reducers), `providers/ReduxStore/middlewares/draft`, `components/RequestPane/QueryUrl` (`onSave`, `hasRequestChanges`).

## 2. Keyboard shortcuts

Registry: `providers/Hotkeys/keyMappings.js`, implemented with **Mousetrap**. User overrides live in preferences (`app.preferences.keyBindings`); combinations are per-OS strings joined by `+bind+` (e.g. `command+bind+enter`) so they serialize.

| Group       | Default bindings                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------------------- |
| Tabs        | ⌘/Ctrl + W close; ⌘/Ctrl + 1..8 switch position; (hidden) tab positions 3–8                                                |
| Sidebar     | ⌘/Ctrl + F search; ⌘/Ctrl + C copy item; ⌘/Ctrl + V paste item; ⌘/Ctrl + D clone; ⌘/Ctrl + R rename; ⌘/Ctrl + `\` collapse |
| Requests    | ⌘/Ctrl + Enter send; ⌘/Ctrl + J change orientation; Alt + Shift + F prettify                                               |
| Editor      | Alt + Space (mac) / Ctrl + Space trigger autocomplete                                                                      |
| Collections | ⌘/Ctrl + O import; ⌘/Ctrl + E edit environment; ⌘/Ctrl + N new request                                                     |
| Search      | ⌘/Ctrl + K global search                                                                                                   |
| View        | ⌘/Ctrl + = / - / 0 zoom                                                                                                    |
| Developer   | ⌘/Ctrl + T open terminal                                                                                                   |
| Other       | ⌘/Ctrl + , preferences; quit                                                                                               |

Display strings are generated by `getKeyBindingDisplayTextByOS` (e.g. `⌘ + ↩` on macOS, `Ctrl + Enter` elsewhere) — tested in `keyMappings.spec.js`.

`useKeybinding`, `useKeybindingDisplayText` expose bindings to components; `keybindingsEnabled` gates them.

## 3. Variable autocomplete

Triggered while typing inside any request editor:

- Prefix `{{` opens a completion list of all in-scope variables grouped by scope, with the effective value and provenance.
- Completion respects the same precedence as execution (`utils/variables`).
- Enter inserts `{{name}}`; Escape dismisses.
- Works inside URL, headers, bodies, scripts, tests, assertions, and auth fields.

---

## 4. Set-as-variable

Select response text → context menu **Set as variable** (`SetAsVariableMenu`, `SetAsVariablePopover`, `providers/SetAsVariable`):

1. Suggest a name from the JSON path / header name.
2. Choose target scope (environment, collection, folder, request, runtime, global).
3. Optionally replace the selected text in the request with `{{name}}` (the "replace reference" behavior added in commit `9801`, limited to HTTP requests).
4. Persist (env requires a save; runtime is immediate).

---

## 5. Bulk editing

`BulkEditor` provides a raw `Name: Value` text mode for headers and query params, with a toggle back to the table. Pasting `curl` output or copied header blocks is a primary workflow.

## 6. Modals, dialogs, confirmations

| Pattern       | Component                                                      | Used for                                                                  |
| ------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------- |
| Modal         | `ui/Modal` + `Portal`                                          | New request/folder/collection, import wizards, generate code, preferences |
| Confirmation  | `ConfirmCloseEnvironment`, `ConfirmAppClose/SaveRequestsModal` | Unsaved changes                                                           |
| Inline prompt | `CreateExampleModal`, `PromptVariables`                        | Naming, `{{?Prompt}}` values                                              |
| Toast         | `providers/Toaster`                                            | Success/failure of background ops                                         |
| Error banner  | `ErrorBanner`                                                  | Non-blocking errors                                                       |

Rules observed:

- Modals trap focus and restore it on close (`useFocusTrap`).
- Escape closes; primary action is Enter when a text field is focused.
- Destructive actions require explicit confirmation.

---

## 7. Menus and context menus

`ui/MenuDropdown` and `ui/ContextMenu` render items with icon, label, shortcut hint, disabled reason, and separators. Items with destructive intent use the danger color.

Context menus appear on: sidebar rows, tabs, response text selection, cookies, table rows.

---

## 8. Tables

`EditableTable` (with `ReorderTable`, `SortableEditableTableRows`) powers params, headers, form bodies, vars and assertions:

| Behavior       | Detail                                                            |
| -------------- | ----------------------------------------------------------------- |
| Row add/delete | With sensible defaults (last row always addable)                  |
| Enable/disable | Checkbox per row; disabled rows are preserved and still visible   |
| Drag reorder   | Pointer-based (`useMouseRowDrag`, `useSortableEditableTableRows`) |
| Column resize  | Drag handles; widths persisted per table per tab                  |
| Inline edit    | Single-line editors with autocomplete                             |
| Paste          | Multi-row paste splits on newlines/tabs                           |
| Keyboard       | Tab moves cell, Enter commits                                     |

---

## 9. Sending and cancellation

- Enter (with modifier) sends; the Send button becomes **Cancel** and stays visible.
- Re-sending while in flight cancels the previous request first.
- The response pane keeps the previous response visible until the new one arrives (stopwatch shows progress).
- Prompt variables may interrupt sending with a modal.

---

## 10. Notifications of background work

| Work           | Feedback                                         |
| -------------- | ------------------------------------------------ |
| Save           | Tab dot clears; toast on error                   |
| Import         | Progress modal → report (`PostmanPackageReport`) |
| Runner         | `RunnerResults` panel, live timeline             |
| Watcher reload | Silent item refresh; toast if parse fails        |
| Git operations | Section status + toasts                          |

---

## 11. Go port guidance (PROPOSED)

- Reproduce the draft model and the dirty-tab dot; it is how users know what is saved.
- Shortcut system must be user-remappable and OS-aware; store as structured bindings, not strings.
- Autocomplete of variables is a high-value feature — implement with provenance markers.
- Keep "disabled rows persist" behavior in tables.

## 12. Interaction behaviour supplied by Lobe MyGo (VERIFIED)

Sections 1–11 describe Bruno's interactions and are the behaviour contract. This section records which parts of that contract **the component library already implements** and which we must implement ourselves. Where Lobe implements a pattern, adopt its semantics rather than rebuilding them, because keyboard handling is easy to get subtly wrong.

### 12.1 Patterns Lobe implements for us

| Pattern (§)                 | Lobe behaviour                                                                                                                                                                                                                                             | Consequence for our code                                                                                                                                                                      |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Menus (§7)                  | `overlay.DropdownMenu(c, open *bool, p, trigger func(t ui.Element)) string` — opens on the trigger, or Enter / Space / Down; **returns the chosen key**, closing itself                                                                                    | Store only `open` and dispatch on the returned key. `MenuItem{Icon, Label, Hotkey, Extra, Danger, Disabled, Divider}` covers icon/label/shortcut/disabled/separator/destructive from §7       |
| Context menus (§7)          | `overlay.ContextMenu(c, target, p) string` — opens on secondary click or Ctrl-click on macOS, and on the menu key or Shift+F10 while focused                                                                                                               | Attach to sidebar rows, tabs, table rows as §7 requires; no custom hit-testing                                                                                                                |
| Shortcut _hints_ (§2)       | `MenuItem.Hotkey` and `TooltipProps.Hotkey` **display** a binding (`"mod+d"`) in a key cap                                                                                                                                                                 | Hints never bind keys — binding stays in our keymap, so the keymap remains the single source of truth                                                                                         |
| Key capture (§2)            | `field.HotkeyInput` records a shortcut into `*string`; requires a modifier plus one key; refuses values in `Conflicts []string` and reports them through `OnConflict`                                                                                      | This is the settings UI for remapping. Feed `Conflicts` from the live keymap — it makes §2's "user-remappable" requirement enforceable at capture time                                        |
| Confirmations (§6)          | `feedback.Modal(c, open *bool, p, content) bool` returns `true` in the frame OK is pressed and **leaves `*open` to the caller**                                                                                                                            | Closes only after the action succeeds — exactly the pattern §6 describes for destructive actions                                                                                              |
| Escape / backdrop dismissal | `DropdownMenu`, `Popover`, `Modal`, `Drawer`, `FloatingPanel`, `FloatingSheet` all document Escape and outside-press closing; `ModalProps.NoFooter` and `DrawerProps.NoCloseButton` opt out of the visible affordances without removing the keyboard paths | No custom focus-trap or dismiss logic needed                                                                                                                                                  |
| Inline rename               | `field.EditableText(c, value *string, editing *bool, p)` — Enter or the save button writes the draft, Escape drops it; a changed draft shows reset and save                                                                                                | Use for renaming tabs, collection items and environment names (§ covered by the draft model, §1)                                                                                              |
| Toasts (§10)                | `feedback.ToastHost` once in the root view; `feedback.ShowToast(c, ToastProps{ID, Title, Description, Type, Timeout, Action, OnAction})` returns an ID; showing a toast with an existing ID **updates it**; timeout pauses while hovered                   | The ID is the mechanism for progress→success transitions (e.g. import or runner): show a `ToastLoading` toast, then re-show the same ID as `ToastSuccess`. `Timeout < 0` means “until closed” |
| Row hover actions           | `display.ListItem.Actions` builds buttons shown while hovered or focused; `ShowAction` pins them                                                                                                                                                           | Matches Bruno's hover-revealed row actions without custom hover state                                                                                                                         |
| Search with shortcut        | `field.SearchBar` — `ShortKey: "mod+k"` focuses it from anywhere in the window and shows the key as a tag while empty                                                                                                                                      | Sidebar filter and collection search need no custom global shortcut wiring                                                                                                                    |
| Drag reorder                | `layout.SortableList(c, items *[]T, key func(T) string, p, row func(item T, handle func()))` — drag by the handle, **plus keyboard reorder**: Space picks up and drops, arrows move, Escape reverts                                                        | This is the accessible reorder primitive for tabs, params, headers and env vars. Bruno's §8 drag reorder has no keyboard equivalent; Lobe's does                                              |
| Numeric stepping            | `field.InputNumber` — arrows and Up/Down step by `Step`, clamped to `Min`/`Max`, applied on Enter or blur                                                                                                                                                  | Use for runner iterations, delay, port, timeout settings                                                                                                                                      |
| Password entry              | `field.InputPassword` — hides content with a reveal button                                                                                                                                                                                                 | Environment secrets, proxy passwords, client-cert passphrases                                                                                                                                 |
| File picking                | `field.Upload` with `PickFiles(PickOptions{Accept, Multiple, Directory})` returning `[]File{Name, Path, Type, Size, Data}`                                                                                                                                 | Multipart file rows and import dialogs                                                                                                                                                        |
| Boolean choices             | `choice.Switch`, `choice.Checkbox`, `choice.ToggleGroup`, `choice.RadioGroup`                                                                                                                                                                              | Enabled flags, settings toggles, body mode                                                                                                                                                    |

### 12.2 Where Lobe's semantics differ from Bruno's, and what we do

| Bruno behaviour                                  | Lobe behaviour                                          | Decision                                                                                                           |
| ------------------------------------------------ | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Table cells: Tab moves cell, Enter commits (§8)  | No table component; `field.Input` commits on Enter/blur | Implement the cell grid ourselves and keep Tab/Enter semantics (§8 is the contract)                                |
| Reorder by pointer drag only (§8)                | `SortableList` adds keyboard reorder                    | **Adopt Lobe's** — strictly more accessible, no compatibility loss                                                 |
| Dropdown closes on choose                        | Same                                                    | No change                                                                                                          |
| Toast auto-dismiss ~fixed                        | `Timeout` configurable per toast, paused on hover       | Use longer timeouts for errors; `-1` for errors that need acknowledgement                                          |
| Modal closes on OK unconditionally               | Caller closes after the action succeeds                 | **Adopt Lobe's** — prevents closing a dialog on a failed save                                                      |
| Shortcut strings in one place (`keyMappings.js`) | Hints and capture both use `"mod+shift+k"` strings      | Keep the keymap structured (§11) and convert at the boundary with `display.HotkeyBinding` / `display.FormatHotkey` |

### 12.3 Patterns we must implement

| Pattern                           | Why not Lobe                                                                                                 | Notes                                                                                                |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `{{variable}}` autocomplete (§3)  | `field.AutoComplete` matches typed text against options but cannot be embedded inside a code editor's buffer | Custom completion in the MyGo `ui/editor`; `field.AutoComplete` remains useful for standalone fields |
| Set-as-variable on selection (§4) | No selection-aware response widget                                                                           | Custom: `code.Highlighter` is read-only, so selection capture needs the editor                       |
| Multi-row paste (§8)              | No table                                                                                                     | Custom grid; split on newlines and tabs                                                              |
| Cell Tab/Enter navigation (§8)    | No table                                                                                                     | Custom grid                                                                                          |
| Send/Cancel swap (§9)             | `action.ActionIcon` changes icon but state is ours                                                           | Swap icon + `Title` and keep both wired to the same presenter action                                 |
| Dirty tab dot (§1)                | `display.Badge` with `Dot: true` gives the visual                                                            | Use `Badge{Dot: true}` on the custom tab; the draft state itself is ours                             |

### 12.4 Rule of thumb

If a pattern involves **keyboard interaction, dismissal, or focus**, use the Lobe component. If it involves **an editable grid, a code buffer, or a tree**, build it. The dividing line is visible in `ui/components.md` §6.6: all eight custom widgets are grids, buffers or trees.
