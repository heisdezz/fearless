# Interaction Patterns

Status: VERIFIED unless marked.

---

## 1. Draft model (the central interaction rule)

Every edit writes to `item.draft`; nothing is written to disk until the user saves (or autosave fires).

```js
if (!item.draft) item.draft = cloneDeep(item);
item.draft.request.url = action.payload.url;
```

Consequences visible in the UI:

| Indicator | Meaning |
|---|---|
| Dot on tab | Draft differs from saved |
| Save button enabled | `hasRequestChanges(item)` true |
| Save shortcut | ⌘/Ctrl + S |
| Autosave | Optional debounce (`enable auto save`, `auto save delay`) |
| Close-with-changes | Confirmation dialog (`ConfirmAppClose/SaveRequestsModal`) |
| External file change | Watcher updates `item`, draft retained |

Source: `slices/collections/index.js` (reducers), `providers/ReduxStore/middlewares/draft`, `components/RequestPane/QueryUrl` (`onSave`, `hasRequestChanges`).

## 2. Keyboard shortcuts

Registry: `providers/Hotkeys/keyMappings.js`, implemented with **Mousetrap**. User overrides live in preferences (`app.preferences.keyBindings`); combinations are per-OS strings joined by `+bind+` (e.g. `command+bind+enter`) so they serialize.

| Group | Default bindings |
|---|---|
| Tabs | ⌘/Ctrl + W close; ⌘/Ctrl + 1..8 switch position; (hidden) tab positions 3–8 |
| Sidebar | ⌘/Ctrl + F search; ⌘/Ctrl + C copy item; ⌘/Ctrl + V paste item; ⌘/Ctrl + D clone; ⌘/Ctrl + R rename; ⌘/Ctrl + `\` collapse |
| Requests | ⌘/Ctrl + Enter send; ⌘/Ctrl + J change orientation; Alt + Shift + F prettify |
| Editor | Alt + Space (mac) / Ctrl + Space trigger autocomplete |
| Collections | ⌘/Ctrl + O import; ⌘/Ctrl + E edit environment; ⌘/Ctrl + N new request |
| Search | ⌘/Ctrl + K global search |
| View | ⌘/Ctrl + = / - / 0 zoom |
| Developer | ⌘/Ctrl + T open terminal |
| Other | ⌘/Ctrl + , preferences; quit |

Display strings are generated by `getKeyBindingDisplayTextByOS` (e.g. `⌘ + ↩` on macOS, `Ctrl + Enter` elsewhere) — tested in `keyMappings.spec.js`.

`useKeybinding`, `useKeybindingDisplayText` expose bindings to components; `keybindingsEnabled` gates them.

## 3. Variable autocomplete

Triggered while typing inside any request editor:

- Prefix `{{` opens a completion list of all in-scope variables grouped by scope, with the effective value and provenance.
- Completion respects the same precedence as execution (`utils/variables`).
- Enter inserts `{{name}}`; Escape dismisses.
- Works inside URL, headers, bodies, scripts, tests, assertions, and auth fields.

---

## 4. Set-as-variable

Select response text → context menu **Set as variable** (`SetAsVariableMenu`, `SetAsVariablePopover`, `providers/SetAsVariable`):

1. Suggest a name from the JSON path / header name.
2. Choose target scope (environment, collection, folder, request, runtime, global).
3. Optionally replace the selected text in the request with `{{name}}` (the "replace reference" behavior added in commit `9801`, limited to HTTP requests).
4. Persist (env requires a save; runtime is immediate).

## 5. Bulk editing

`BulkEditor` provides a raw `Name: Value` text mode for headers and query params, with a toggle back to the table. Pasting `curl` output or copied header blocks is a primary workflow.

## 6. Modals, dialogs, confirmations

| Pattern | Component | Used for |
|---|---|---|
| Modal | `ui/Modal` + `Portal` | New request/folder/collection, import wizards, generate code, preferences |
| Confirmation | `ConfirmCloseEnvironment`, `ConfirmAppClose/SaveRequestsModal` | Unsaved changes |
| Inline prompt | `CreateExampleModal`, `PromptVariables` | Naming, `{{?Prompt}}` values |
| Toast | `providers/Toaster` | Success/failure of background ops |
| Error banner | `ErrorBanner` | Non-blocking errors |

Rules observed:

- Modals trap focus and restore it on close (`useFocusTrap`).
- Escape closes; primary action is Enter when a text field is focused.
- Destructive actions require explicit confirmation.

## 7. Menus and context menus

`ui/MenuDropdown` and `ui/ContextMenu` render items with icon, label, shortcut hint, disabled reason, and separators. Items with destructive intent use the danger color.

Context menus appear on: sidebar rows, tabs, response text selection, cookies, table rows.

---

## 8. Tables

`EditableTable` (with `ReorderTable`, `SortableEditableTableRows`) powers params, headers, form bodies, vars and assertions:

| Behavior | Detail |
|---|---|
| Row add/delete | With sensible defaults (last row always addable) |
| Enable/disable | Checkbox per row; disabled rows are preserved and still visible |
| Drag reorder | Pointer-based (`useMouseRowDrag`, `useSortableEditableTableRows`) |
| Column resize | Drag handles; widths persisted per table per tab |
| Inline edit | Single-line editors with autocomplete |
| Paste | Multi-row paste splits on newlines/tabs |
| Keyboard | Tab moves cell, Enter commits |

---

## 9. Sending and cancellation

- Enter (with modifier) sends; the Send button becomes **Cancel** and stays visible.
- Re-sending while in flight cancels the previous request first.
- The response pane keeps the previous response visible until the new one arrives (stopwatch shows progress).
- Prompt variables may interrupt sending with a modal.

---

## 10. Notifications of background work

| Work | Feedback |
|---|---|
| Save | Tab dot clears; toast on error |
| Import | Progress modal → report (`PostmanPackageReport`) |
| Runner | `RunnerResults` panel, live timeline |
| Watcher reload | Silent item refresh; toast if parse fails |
| Git operations | Section status + toasts |

## 11. Go port guidance (PROPOSED)

- Reproduce the draft model and the dirty-tab dot; it is how users know what is saved.
- Shortcut system must be user-remappable and OS-aware; store as structured bindings, not strings.
- Autocomplete of variables is a high-value feature — implement with provenance markers.
- Keep "disabled rows persist" behavior in tables.
